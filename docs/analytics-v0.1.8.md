# ver0.1.8 利用状況計測定義

状態: 実装済み / 本番送信先は未接続 / 公開日は未定

送信はアプリ内の「改善に協力する」を選んだ後だけ開始する。「あとで」
では送信もランダムID作成も行わない。設定から停止でき、停止時はランダムID、
セッション、未送信キューを削除する。

送信項目はイベント定義v1、イベントID、発生時刻、ランダムなインストールID、
共有セッションID、アプリ版、UI言語、実行環境、許可されたイベント属性のみ。
メモ本文、ファイル名・パス、ウィンドウタイトル、クリップボード、氏名・メール、
ハードウェア識別子、生の例外メッセージは送信しない。

イベントは、参加開始、セッション開始、最初の実編集、中核操作成功、
オンボーディングの表示・手順・完了・スキップ、既定アプリ・レビュー案内、
ファイル読込・保存の成功・キャンセル・失敗を対象とする。復元は実編集・
中核操作に数えず、IME変換中は編集確定としない。既定アプリ設定画面を
開いたことは設定成功とは扱わない。

ローカルキューは最大500件か512KiB、最長30日、1回20件、5秒でタイムアウト。
再試行は1分、5分、30分、2時間、8時間の最大5回。通常の編集・保存を待たせず、
受信側はイベントIDで重複排除する。D1の生データは90日で削除する。

公開前に、現在の公開プライバシーポリシーに上記の収集目的、Cloudflareへの
送信、ランダムID、90日保持、停止方法を反映する必要がある。
