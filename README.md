# Always Memo

作業中にすぐにメモを取れる、作業の邪魔をしない、を第一に考えて作成したwindows向けのデスクトップアプリです。
「常に見えるが、邪魔をしない」ことを意識して開発を行いました。

現在はMicrosoft Storeで公開中です。個人開発アプリとして、企画から配布までを一人で行いました。

##　概要

作業中にメモを取りたい場面では、既存のメモアプリを開いたり、ウィンドウを切り替えたり、邪魔じゃない位置に変えたりと使用をするうえで面倒なことがとても多いです。

Always Memoではそのような課題を解決するために開発された、在駐型のメモアプリです。
在駐表示やウィンドウ位置移動、ショートカット操作に対応し、作業中でも素早くメモを確認・編集できます。

## 作成背景

普段の課題や開発中に、調べたことや必要なことを手軽にメモしたい場合がとても多かったのですが、様々なウィンドウを開く状況でメモウィンドウが埋もれて迷子になってしまう場合がたくさんありました。

そのようなストレスから最前面に表示するwindowsメモ帳に似たメモ帳を作成しようと考えました。

また最前面に表示する場面でネックとなる画面の占有をショートカットでウィンドウ位置を切り替えできるようにする機能追加によってネックをも解決した、個人的な悩みを解決したメモアプリを開発することが出来ました。

## 主な機能

- 常に手前に表示する Always on Top 機能
- 複数メモを管理できるタブ機能
- メモ内検索・置換
- 指定行へのジャンプ
- `.txt` / `.md` ファイルの読み込み・保存
- グローバルショートカット
- ウィンドウを画面端へ移動するスナップ操作
- ライト / ダーク / システムテーマ対応
- フォントサイズ調整
- 行間調整
- 右端での折り返し設定
- ステータスバー表示切り替え
- 多言語対応
- Microsoft Storeでの配布

## 工夫点

### UI,UX

個人的にUI,UXはwindowsでのメモ帳がかなり洗礼されている、かつ有名でなじみのあるものだと考えたので、基本的な構図はwindowsメモ帳を参考に作成した。

しかし小さい画面での設定などが見にくいなどの課題が発生したため、別ウィンドウに設定画面を移すようにすることやドロップダウンメニューをどのように表示するかを工夫した。

### Tauriを用いた軽量なデスクトップアプリ化

個人的に軽量なアプリというものを目指していたので、技術スタックにはTauriを採用しました。

他のフレームワークとも比較して、自分にとって一番都合の良いフレームワークを選ぶという経験をするためにも、技術スタックを考えることには特に注力した。

### Microsoft Storeへの掲載

多くの人に使ってもらえるようにストアへの掲載を行いました。

その中でスクリーンショットを作ることやアプリの魅力、多言語化など開発をするだけでなく、アプリを使ってもらえるようにするという作業を行ったことはとても良い経験になったと感じています。

### セキュリティ面の見直し

ユーザーが入力するテキストやローカルファイル操作を扱うため、入力内容の扱い方やTauri APIの呼び出し範囲に注意しました。

オフラインのメモ帳ということで全然リスクはないのではないかと考えていたが、調べてみると様々なリスクがあると気づき、それを対策したのは、今後アプリケーションを公開する中で、価値観を変える経験になったと感じました。

### LP,オンボーディングの工夫

素早くかつ簡単にアプリの魅力を作成するためにランディングページとヘルプのページを作成して、よりよいユーザ体験をできるようにしました。

特にヘルプに関しては、ショートカット機能の説明などを特に工夫して作成しました。
またアプリ内でもどのように使えばいいのかを簡単に確認できるように主要機能のショートカットの表示とヘルプページへの導線を作成しました。

またアプリのstoreへの公開に伴い、LPも整備して様々な場所からの集客を見込もうと工夫をしました。
